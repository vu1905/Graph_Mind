# ⚛️ Frontend (React Web)

Mã nguồn ứng dụng Web SPA (Single Page Application) sử dụng React.

## 📂 Cấu trúc thư mục

* `public/`: Chứa file `index.html` và tài nguyên tĩnh công khai.
* `src/assets/`: Hình ảnh, icons, styles dùng chung.
* `src/components/`: Nơi chứa các giao diện component:
  * `Admin/`: Quản trị hệ thống.
  * `Auth/`: Đăng nhập, đăng ký.
  * `DashboardLogged/`: Bảng điều khiển người dùng.
  * `Features/`: Các tính năng ứng dụng.
  * `Landing/`: Giao diện trang chủ.
* `src/services/`: Các hàm gọi API tới Backend Server.

## ⚡ Hướng dẫn chạy

```bash
npm install
npm start
```
